# DouyinBridge v0.7.0 — 自动浏览与定时分享

这是**实验性的本机功能**。原生卡片分享沿用 dsh-douyin-agent 的分享面板和回执核验，但自动推荐流和真实发送尚未完成抖音账号的端到端测试。离线 CI 通过不能证明实际发送成功。

## 配置

更新后备份 `data/allowlist.sqlite`。建议先在 `.env` 只开启浏览，禁止自动发送：

```ini
ENABLE_AUTO_BROWSING=true
ENABLE_SENDING=false
ENABLE_AUTO_SHARING=false
```

确认浏览、候选视频和登录状态正常后，再用测试联系人验证原生分享，并明确设置：

```ini
ENABLE_SENDING=true
ENABLE_AUTO_SHARING=true
```

**注意：** ENABLE_SENDING=true 也允许之前已授权会话中的普通文字回复。更改环境变量需要重启程序。

## 管理后台

1. 打开 `http://127.0.0.1:3219/` 并输入管理员令牌。
2. 在“会话授权”中单独给目标私聊或群聊开启普通白名单和 **定时主动分享** 两个权限。
3. 新建任务：目标会话、北京时间浏览时刻、分享时刻、数量及可选主题关键词。
4. 新任务默认关闭。启用后，浏览和分享任务会按计划分别执行。
5. 先通过“手动浏览”核对候选池；也可手动添加精确作品 URL：`https://www.douyin.com/video/数字`。
6. 查看“原生分享回执”。状态不确定时先在抖音核对，再由管理员明确标记实际结果。

## 功能与限制

- 推荐流模式使用独立视频标签页，检查实际视频身份、页面状态和短时间播放进度，借助上游核验换片逻辑浏览有限数量的作品。
- 主题模式使用抖音网页搜索，逐个访问可信搜索结果，并核实作品播放状态。
- 候选数据是有限的页面观察结果，不声称完整看过作品，也没有启用 AI 内容判断。
- 分享复用上游 `VideoForwarder.forwardAutonomous`，核对群聊/好友稳定身份、作品 ID、分享按钮与发送后的新作品卡片回读；不把“文字链接”当作原生卡片确认。
- 自动分享与 AstrBot 文本回复共用串行发送队列。分享完成或结果不明都写入 SQLite，另有上游独立收据保存在 `data/automation-upstream/`，不要删除。
- 每会话 24 小时最多 2 次尝试，全局最多 12 次、间隔至少 30 分钟。对同一收件人和视频 ID 永久去重。
- 每天任务按 `Asia/Shanghai` 运行，只有计划时间后 15 分钟内才触发。错过的时间窗口不进行批量补发。
- 如果浏览器崩溃或发送结果无法确认，状态 `reserved` / `uncertain` 会阻塞目标会话后续自动分享，直到人工核实，系统绝不自动重试。
- 本功能**没有实现 Docker 部署**、自动点赞、评论或绕过平台安全验证。平台可能限制自动化浏览与分享，应控制频率并遵守平台规则。
