# 分享视频 / 图文卡片与按需采样

> 适用于 DouyinBridge v0.7.0。这里区分“读取分享卡片元数据”与“按明确请求短时采样真实视频画面”，两者不是同一种能力。

## 1. 收到分享卡片时

- 对已授权私聊与群聊，识别上游 `ChatBrowser.readConversation()` 中的 `media.type === 'shared-work'`。
- 即使原始消息没有文字，也可以转成 OneBot v11 文本消息，包含可见标题、作者、作品 ID 等字段。
- **只有作品 URL、作品 ID、来源卡片彼此一致且可信时**才转发可点击链接；未核验的链接不对外提供。
- 图文与视频分别标识。此时只获取网页显示的分享卡片元数据，**没有看完整视频，也没有听到音频**。
- 首次扫描建立消息基线，避免把历史分享自动重播给 AstrBot；群聊要求能够核实发送成员身份。
- `SHARED_VIDEO_FORWARDING=false` 可以关闭此类卡片转发（修改 `.env` 后需重启）。

## 2. 可选封面

在 Web 管理后台先开启目标会话的普通白名单，再独立开启 **视频卡片封面**。

- 私聊新分享可以尝试调用上游 `captureMessage`。
- 群聊只有原分享消息 `mentionedSelf===true` 时才尝试封面截图。
- 核验来源后将单张 JPEG 封面作为 OneBot `image` 消息段发送给 AstrBot。
- 获取失败时仍可转发文字元数据。单张封面**不能作为视频全部内容的证据**。

## 3. 按需视频分时采样（v0.5.0 起）

当前版本已实现**受授权控制的短时视频画面采样代码**，但仍需真实抖音环境联调。这与普通分享卡片转发是分开的功能。

- 必须单独开启会话的 **按需视频分时采样** 权限。
- 私聊需要用户明确提出分析请求，例如“帮我分析这个视频”。
- 群聊需要同一位发送分享卡片的成员 **@机器人** 并明确提出分析请求。
- 网关核验作品身份，使用独立临时 Chromium 标签页静音播放默认 3 秒，尝试得到 3 张有时间信息的 JPEG 帧，通过 OneBot 图片段交给 AstrBot。
- 采样时长可通过 `VIDEO_SAMPLE_SECONDS` 设置为 1～5 秒。每会话 90 秒冷却、滚动 24 小时最多 5 次、全局最多 30 次。
- 不收集音轨，不保证覆盖整个视频或理解所有字幕、画面；如无法取得真实画面，必须明确声明失败。

详细原理与限制见 [真实视频分时采样](video-sampling.md)。

## 示例（虚构）

```text
[抖音分享视频]
标题：示例标题
作者：示例作者
作品ID：123456789
作品链接：https://www.douyin.com/video/123456789
内容范围：仅已显示的分享卡片元数据，未观看视频或收听音频。
```

## 测试边界

GitHub Actions 的单元测试不代表账号实际播放、群聊 @ 身份识别及 AstrBot 多模态适配已完成真实验收。操作需遵守平台规则和授权边界。
